[imgproxy Pro](https://imgproxy.net/#pro) is the paid edition of imgproxy. The library builds the URL for every option, whichever edition you run. What imgproxy does with a Pro option on the open-source edition is up to imgproxy: it may ignore the option or answer with an error. Check the edition before you depend on one.

## How the docs mark Pro

- A **Pro** badge in the sidebar and in the lists marks an option that needs Pro as a whole.
- **Partly Pro** marks an option that works on both editions, with a value or an argument that needs Pro.
- Every option page has an *Availability* row.
